# Термин зертханасы

Қазақша термин баламаларын және индонез, малай, қытай тілдеріндегі атауларды ашық Wikipedia мәтіндері арқылы салыстыратын **алғашқы прототип**. Сайт қазақ тілінде жұмыс істейді, екі дайын мысал бар және жаңа терминге баламаларды қолмен қосуға болады.

## Іске қосу

`index.html` файлын браузерде ашыңыз. Дерек алу үшін интернет және Wikipedia API-іне қолжетімділік қажет. Файлдан ашқанда браузер желілік сұрауларды шектесе, осы қалтада `python -m http.server 8000` командасын орындап, `http://localhost:8000/` мекенжайын ашыңыз. Сайттың өзіне ешқандай жинақтау құралы, кілт немесе сервер қажет емес.

## GitHub Pages-ке шығару

1. GitHub-та жаңа репозиторий жасаңыз, мысалы `termin-zertkhanasy`.
2. Осы қалтадағы **барлық файлды** репозиторийдің түбіріне салыңыз (`index.html` түбірде қалсын).
3. `Settings → Pages → Build and deployment` бөлімінде `Deploy from a branch`, `main`, `/ (root)` таңдаңыз да сақтаңыз.
4. GitHub көрсеткен `https://<username>.github.io/<repo>/` мекенжайын ашыңыз. Бұл нұсқада барлық жергілікті сілтеме салыстырмалы, сондықтан репозиторий ішіндегі жолмен де жұмыс істейді.

Желіге байланысты көрсеткіштер әр ашылған сайын қайта алынады. `.nojekyll` файлы GitHub Pages-тің артық өңдеуін өшіреді.

## Дерек қалай есептеледі

Әр нұсқа үшін MediaWiki Action API-іне `action=query&list=search` сұрауы жіберіледі. Тіркес тырнақшаға алынады, тек негізгі мақала кеңістігі (`srnamespace=0`) ізделеді, нәтиже `searchinfo.totalhits` өрісінен алынады. `origin=*` браузердің ашық CORS сұрауы үшін қажет.

**Сан — іздеу нәтижесіндегі мақалалар саны.** Бұл сөздің барлық қайталану саны емес. Іздеу индексі нұсқаларды талдайтындықтан, ол абсолют дәл лексикалық санақ та емес. Бір мақала бірнеше нұсқаға енуі мүмкін. Тілдік Wikipedia белгілі ел халқының толық мәтін корпусы емес; әр тілдегі абсолют сандарды тікелей салыстырмаңыз. API қатесі немесе байланыс болмаса `—` көрсетіледі, `0` көрсетілмейді.

Алғашқы екі үлгінің термин және өзге тілдегі атаулары қолмен таңдалды, олар ресми стандарт ретінде белгіленбейді. Жаңа терминге агент автоматты аударма ойлап таппайды; пайдаланушы баламаларын енгізеді. «Автоматты қорытынды» — алынған сандарға негізделген ережелік мәтін, тілдік модельдің дербес жауабы емес. Нақты терминологиялық база, көпсалалы мәтін корпусы және LLM талдауы кейінгі кезеңде серверлік жүйемен қосылады.

Дереккөздер: [MediaWiki Search API](https://www.mediawiki.org/wiki/API:Search), [CirrusSearch тіркес іздеуі](https://www.mediawiki.org/wiki/Help:CirrusSearch), [CORS сұраулары](https://www.mediawiki.org/wiki/API:Cross-site_requests), [hard disk ұғымы](https://www.wikidata.org/wiki/Q4439), [computer mouse ұғымы](https://www.wikidata.org/wiki/Q7987).

## Құрамы

- `index.html` — негізгі бет пен қолжетімді интерфейс;
- `styles.css` — бейімделетін дизайн;
- `app.js` — мысалдар, API сұрауы, салыстыру және қорытынды;
- `favicon.svg`, `.nojekyll` — белгіше және Pages параметрі.
