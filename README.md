# Термин зертханасы

Информатика терминдерінің қазақша баламаларын дереккөзбен салыстыратын GitHub Pages сайты. Қазақша, орысша не ағылшынша іздеуге, баламаларды өңдеуге, CSV импорттауға және алты басқа тілдегі нәтижені қарауға болады.

**Ауқымы:** бастапқы каталогта 133 редакциялық ұғым бар. Бұл информатикадағы барлық термин емес. [Termincom информатика саласында](https://termincom.kz/industry/?id=28) 10 016 жазба көрсетеді; олар толық көшірілмеді. Ашық жүктеу шарты мен әр ұғымның сәйкестігін тексермей, дерекқорды тұтас енгізу дұрыс болмайды. Жоба тексерілген CSV арқылы 20 000 жазбаға дейін кеңейе алады. Каталогта жоқ терминді Wikidata-дан іздеп, атауын қолмен түзетуге болады.

## Жариялау

1. Осы бумадан `python3 -m http.server 8000` орындап, `http://localhost:8000/` ашыңыз.
2. GitHub репозиторийінің **түбіріне** осы архив ішіндегі барлық файлды, соның ішінде `index.html`, `data/`, `.github/` және `.nojekyll` жүктеңіз.
3. `Settings → Pages → Build and deployment` ішінен `Deploy from a branch`, `main`, `/ (root)` таңдаңыз.
4. `https://<username>.github.io/<repo>/` бетін ашыңыз. Жергілікті файл сілтемелері салыстырмалы.

Негізгі сайтқа npm, серверлік код немесе API кілті қажет емес. Пайдаланушы браузерінен Wikipedia/Wikidata API-іне қолжетімділік қажет. API істемесе `—` көрсетіледі, сан ойдан шығарылмайды.

## Статистика әдісі

| Бөлік | Есеп | Шектеуі |
| --- | --- | --- |
| Қазақша нұсқалар | `kk.wikipedia.org` ішіндегі тіркес табылған негізгі мақалалар саны, `searchinfo.totalhits` | Сөздің барлық қайталануы емес; іздеу индексі мен көпмағыналылық әсер етеді |
| АҚШ, Германия, Қытай, Оңтүстік Корея, Индонезия, Малайзия | en/de/zh/ko/id/ms Wikipedia бөліміндегі мақала саны | Ел тұрғындарының немесе ұлттық интернеттің нақты жиілігі емес; тілдер арасындағы абсолют сандарды теңемеңіз |
| Тілдік атаулар | Wikipedia-дағы бір ұғымға байланысқан беттер, редактор енгізген баламалар | Байланысқан беті жоқ тілде атауды қолданушы енгізеді; аударма ресми бекіту емес |
| Ұсыныс | Құжатпен расталған нұсқа бөлек; өзге жағдайда қазақша жинақтағы басым байқау | Тең, нөл не толық емес жауапта шешім берілмейді |
| Google нәтижесі | Әкімші іске қосса, SerpApi-дің бөлек жуық бағасы | Нақты сөз санағы емес; ұсынысқа қосылмайды |

Іздеу `action=query&list=search`, `srnamespace=0`, тырнақшаға алынған тіркеспен жүргізіледі. Сандар 12 сағатқа, тілдік байланыстар 7 күнге сол браузерде сақталады. «Қайта тексеру» сан кэшін жаңартады. Әр қатарда түпнұсқа іздеу сілтемесі мен алғашқы мақала мысалдары беріледі. Бір мақала бірнеше нұсқада есептелуі мүмкін. Қысқа көпмағыналы сөздерге қосымша адам тексеруі қажет.

Қорытындыны ережелік алгоритм жазады. Бұл нұсқада сыртқы LLM немесе автономды ЖИ агенті жоқ. Дереккөзсіз атау ресми деп белгіленбейді; «басым» деген тұжырым тек осы мәтін қорына қатысты.

## Каталогты кеңейту

Сайттың CSV өрісі [example-import.csv](./example-import.csv) пішімін қабылдайды: `category,kk,kk_alt,ru,en,wiki`. Баламаларды бір ұяшықта `;` арқылы ажыратыңыз. `kk` міндетті; `en` және `wiki` бос қалуы мүмкін. `wiki` толтырылса, дәл сол ұғымның ағылшын Wikipedia мақала атауы болуы шарт. Қате ұғым шетел баламаларын шатастырады. Браузерде бір импортқа 2 МБ және 2 000 жол шегі бар; мәлімет тек сол құрылғының localStorage жадында қалады.

Бүкіл сайтқа тұрақты жариялау үшін редактор тексерген CSV файлын құрастырыңыз:

`python3 tools/build_catalog.py reviewed_terms.csv`

Скрипт `catalog-user.js` файлын жасап, бір CSV ішінен 20 000 жазбаға дейін қабылдайды. Жасалған файлды репозиторийге commit/push етіңіз. Импорт өзі ресми мәртебе бермейді: әр терминнің мағынасы, баламасы, дереккөзі және пайдалануға рұқсаты тексерілуі керек. Интерфейстегі түзету тек бір браузерге сақталады.

Каталогта жоқ іздеуде Wikidata сипаттамасы бар ықтимал ұғымдарды ұсынады. Адам дәл ұғымды таңдайды; қазақша атау жоқ болса өзі енгізеді.

## Ерікті Google нәтижелерінің бағасы

Google Custom Search JSON API жаңа тұтынушыларға жабық болғандықтан, әкімшілік жинағыш [SerpApi](https://serpapi.com/search-api) Google Search нәтижесінің жуық `total_results` өрісін пайдаланады. Бұл қосымша бөлік ақылы жоспарға немесе квотаға тәуелді; бос `data/web-stats.json` файлында сан жарияланбайды.

1. GitHub `Settings → Secrets and variables → Actions` ішінде `SERPAPI_KEY` repository secret орнатыңыз. Кілт браузерге немесе жария JSON-ға түспейді.
2. `Actions → Жекелеген терминдер бойынша веб бағаларын жаңарту → Run workflow` таңдаңыз; `term_ids` үшін `hdd,mouse` секілді 1–15 ID, `max_queries` үшін 1–100 аралығындағы квота беріңіз.
3. Workflow тек сәтті нәтижелерді `data/web-stats.json` ішіне commit жасайды. Панель тек жиналған ұғымдарда көрінеді. `gl` мен `hl` іздеу орнын/тілін баптайды, ел ішіндегі нақты қолданысты өлшемейді.

`tools/collect_web.mjs` жергілікті де `SERPAPI_KEY`, `TERM_IDS`, `MAX_QUERIES` орта айнымалыларымен іске қосылады. Кілтті кодқа салмаңыз; тарифті іске қоспай тұрып тексеріңіз.

## Файлдар мен тексеру

- `catalog.js` — 133 бастапқы ұғым; `catalog-user.js` — тексерілген жария қосымша.
- `app.js`, `core.js` — интерфейс, API және қорытынды.
- `tools/build_catalog.py` — редакциялық CSV құрастыру; `tools/collect_web.mjs` және `.github/workflows/refresh-web.yml` — ерікті веб жинағы.
- `data/web-stats.json` — жарияланған веб бағасы (бастапқыда бос).
- `tests/app.test.cjs` — каталог, тілдік байланыс, ұсыныс, импорт пен дерек қатесін тексеру.

`node tests/app.test.cjs` және `node --check app.js` орындаңыз. Тест API жауаптарын алмастырады; жарияланған беттегі тірі Wikipedia сұрауын бөлек қараңыз.
